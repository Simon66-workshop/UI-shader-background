# Phase 0 — 砍需求

> 审计编号：FK-CUT-001
> 判定规则：表内每一行必须能勾选「保留 / 砍掉 / 二期」，不允许「再看看」。

## 原规格（过大）

把 2,200+ 现成 shader 背景铺成网站：认领用户名、Immersive/Grid 浏览、9 种稀有度、四种代码格式复制、暗/亮主题、高分屏适配、首屏/片头/加载页/作品集场景、加密、风控、分析后台。

这不是一个最小可用工具，是一个带身份系统的内容平台。

## 砍法

终端工具的唯一闭环：

**看见效果 → 选中一条 → 复制能跑的代码 → 粘进自己的项目。**

做不到这四步的功能，一期不做。

## 一期最小可用终端工具（MUST）

1. 打开页面即可滚动浏览带实时预览的 shader 卡。
2. 可按 9 种效果类型过滤；「All rarities」显示全部。
3. 每张卡可复制四种代码，剪贴板内容含 `createShader` / `setTheme` / `destroy`。
4. 主题切换后，预览与复制代码中的 dark/light 背景色同步。
5. 复制出的 WebGL 模块含 `pixelRatio` 与最大像素边。
6. 无登录、无认领、无付费、无后端写入。

## 非目标（一期禁止做）

- 不要做「Claim yours」即使原型有按钮。
- 不要接邮箱、OAuth、验证码。
- 不要把 2240 个 GLSL 文件写进仓库。
- 不要为了「更像官网」加营销长页。

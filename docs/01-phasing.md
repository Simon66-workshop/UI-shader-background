# Phase 1 / Phase 2 分阶段

> 审计编号：FK-PHASE-001
> 判定规则：任何 PR / 提交若引入二期范围，本文件可直接判失败。

## 一期（本仓库要交付的）

名称：**Fieldkit** — 客户端 shader 背景终端工具。

| 层 | 做什么 | 不做什么 |
|---|---|---|
| 产品 | 浏览、过滤、放大、复制四种代码 | 认领、账号、社区 |
| 设计 | 暗/亮两套工具壳；卡面即 shader | 营销落地页、插画体系 |
| 前端 | WebGL2 预览 + 过程式目录 + 复制模板 | WebGPU 作为预览主路径（复制仍给 WGSL） |
| 后端 | 无。静态/SSR 只读页面 | 任何 POST、用户表、认领表 |
| 安全 | 无 PII、无 cookie 会话、剪贴板需用户点击 | 鉴权、加密存储、风控引擎 |
| 数据 | 目录由种子生成，可单测对账 | 事件采集平台 |

## 二期（明确挪走）

用户指令：「网站、加密、风控全挪到第二阶段」。

| 主题 | 二期内容 | 一期替代 |
|---|---|---|
| 网站 | 认领站、About 长页、SEO 博客、用户主页 | 工具壳：Explore 一页 + 页脚链接 |
| 加密 | 认领签名、邮箱验证、会话、密钥 | 无密钥、无 token |
| 风控 | 抢注、刷复制、滥用限流、审计日志 | 无写接口则无刷写面 |
| 数据 | 漏斗、留存、复制成功率看板 | 验收用本地审计文件，不上报 |

## 阶段门（进二期之前必须全绿）

1. 一期验收表 `docs/04-acceptance.md` 全部 PASS。
2. `docs/AUDIT.md` 有一次完整跑次记录（时间、命令、截图路径、失败项为空）。
3. 二期不得回头改一期复制 API 的函数名：`createShader` / `setTheme` / `destroy`。

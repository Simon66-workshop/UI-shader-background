# 执行 SOP

> 审计编号：FK-SOP-001
> 用法：每个角色在自己的清单上打勾。不能判定对错的句子不准出现。

## 总流程（必须按序）

1. 砍需求（`docs/00-scope-cut.md`）签字。
2. 分阶段（`docs/01-phasing.md`）确认二期名单。
3. 验收表（`docs/04-acceptance.md`）先写后做。
4. 写代码。
5. 跑验收，把结果写入 `docs/AUDIT.md`。
6. 全绿才能 push。

逆序（先写代码再补验收）视为流程失败。

---

## 产品 SOP

每次改需求只准改 `00-scope-cut.md`，然后同步验收表。禁止只改 UI 文案却偷偷加功能。

**开工前**

- [ ] 一期 MUST 六条仍全部成立
- [ ] 二期名单没有被做进代码（Claim、登录、上报）

**验收时**

- [ ] 从冷启动到复制成功 ≤ 3 次点击（过滤可选）
- [ ] 过滤后计数文案与列表长度一致
- [ ] 无「Claim yours」入口

**禁止**

- 用「增强体验」把认领、邮件、付费塞回一期

---

## 设计 SOP

对照原型：暗色工具壳、圆角卡、Grid/Immersive、复制菜单四行。品牌名必须是 **Fieldkit**，不得用 OpenShaders 或原型里的 @handle。

**开工前**

- [ ] 色板只有中性底 + 一个冷灰强调；shader 内容色不受此限
- [ ] 字体 ≤ 2 族
- [ ] 卡片半径大于内部按钮半径（同心圆角）

**验收时**

- [ ] 390px 宽无横向溢出
- [ ] 主题切换后壳与 shader 同时变
- [ ] 无 emoji 图标、无营销紫渐变底

**禁止**

- 把 shader 预览换成静态 JPEG 充当「完成」

---

## 前端 SOP

**开工前**

- [ ] 目录由纯函数生成，单测锁 2240 与配额
- [ ] 预览只走 WebGL2
- [ ] 复制模板与运行时参数同源

**提交前**

- [ ] `npm run typecheck` 退出码 0
- [ ] 画布池在 destroy 时丢失 context 不抛未捕获异常
- [ ] `prefers-reduced-motion` 下 rAF 仍可画一帧但时间不推进

---

## 后端 SOP（一期）

一期 **没有后端任务**。本段是门禁，不是待办。

- [ ] `src/routes` 与 `server/` 不新增用户写入 endpoint
- [ ] 不新建 `migrations/` 业务表
- [ ] 若发现 POST 认领 / 登录：直接判失败，打回二期

二期若启动：先补认领表、幂等、审计日志，再写 UI。不得先做按钮后补库。

---

## 安全审查 SOP（一期）

审查对象是静态工具，不是账号系统。

| 检查 | 通过标准 |
|---|---|
| PII | 源码不含邮箱采集表单 |
| XSS | 复制文本进 clipboard，不进 `innerHTML` |
| 外链 | `target=_blank` 必带 `rel="noopener noreferrer"` |
| 剪贴板 | 只在用户点击的同步/微任务里调用 |
| 依赖 | 不引入可在浏览器发用户数据的分析 SDK |

二期安全（加密、会话、认领抢注）不在本期审查范围，写入 `01-phasing.md` 即可。

---

## 数据分析 SOP（一期）

一期 **不上报**。能做的只有本地对账：

- 稀有度配额测试
- 复制文本关键字测试
- 浏览器冒烟：首页、过滤、复制、主题

需要「复制点击率」时进二期，且必须先写事件字典，再埋点。禁止先塞匿名统计。

---

## 缺陷处理 SOP

1. 用验收表编号命名缺陷（例：`AC-COPY-02`）。
2. 先写失败复现（命令或点击路径），再改代码。
3. 修完必须复跑同一条，把 PASS 写入 `AUDIT.md`。
4. 不允许用「刷新试试」关闭缺陷。
